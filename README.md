## 这一版改了什么

围绕1—100问的主题推进，对内容进行了系统重构。31—100逐题重新写作，补齐利益分配、中层管理、组织收缩与职业转向等主题，使题目、摘要、话术和正文围绕同一个问题。前30问保留核心内容，修正抽取错误、缺失话术、未经核实的比例，以及关于离职、记录和沟通效果的绝对说法。

参考《高性价比人生指南》的按需阅读、投入收益、小步验证和适用限制，给100问加入各自的行动卡。场景分析、步骤与新写示例为独立编辑重构。51道重点题补充了中文书籍、国内文章和职业指导案例作为延伸阅读，未为凑数量强行配满100问。具体阅读范围见[来源与核验](docs/来源与核验.md)，结构变化见[PDF对照与重构](docs/PDF对照与重构.md)。

## 维护与构建

正文唯一源为 `content/questions.json`，来源为 `content/sources.json`，延伸阅读映射为 `content/reading-map.json`。运行 `python build.py` 验证100个编号、四格行动卡、相关题号、来源引用、70条独立话术及长段重复，然后生成网页数据、三个Markdown分册、完整正文和单文件离线版。不要手动编辑生成文件。

本地预览运行 `python -m http.server 8765`，打开 `http://127.0.0.1:8765/`。深链接格式：`#q=61`。部署到子目录无需修改资源路径。
