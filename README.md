# 职场拆局100问

少一点内耗，多一点选择。按场景查询的一套职场工作手册，重构版 2026-10-06。

## 先看效果

- 下载 [`offline.html`](offline.html)，双击即可查看完整页面，无需联网或安装软件。
- [阅读全部100问](book/完整正文.md)；[基础应对01—30](book/01-基础应对.md)；[协作进阶31—60](book/02-协作进阶.md)；[高阶判断与选择61—100](book/03-高阶判断与选择.md)。
- 仓库 [`samuelsin526/-627806`](https://github.com/samuelsin526/-627806)。线上 Pages 是否启用请以仓库 Settings → Pages 显示为准。

每题提供：先判断、第一步、准备成本、可能收益、示例表达、完整拆解、适用边界、参考范围和相关问题。网页支持全文搜索、编号直达、阶段/处境/准备时间筛选、收藏、复制话术、深链接和打印当前题目。收藏仅存在浏览器本地。

## 三个阅读阶段

| 阶段 | 范围 | 主要用途 |
| --- | --- | --- |
| 基础应对 | 01—30 | 临时加活、拒绝、批评、责任与价值呈现 |
| 协作进阶 | 31—60 | 项目接口、变更、合作边界、团队反馈与授权 |
| 高阶判断与选择 | 61—100 | 决策与资源、机会与平台、权益与记录、谈薪和职业路线 |

无需按顺序做完。准备时间是编辑估计，收益是可能改善，不保证结果。普通协作、高风险权限和劳动关系争议不能用同一套操作处理。

## 本轮重构

31—100逐题重写，删除按类别反复套用的正文和话术；补入第三册公开预览提出的组织判断维度。前30问保留核心，修复抽取错误、话术缺失、第30问混入附录，以及离职后果等过度绝对的表达。题号与ima原文不作一一对应，新版是独立重构。

参考《高性价比人生指南》的按需检索、投入收益及适用限制的组织思路，自行编写场景、判断和示例。未复制其研究结论或证据评级。来源状态、具体规则位置与未读范围见[来源与核验](docs/来源与核验.md)。

## 维护与构建

正文唯一源为 `content/questions.json`，来源为 `content/sources.json`。运行 `python build.py` 验证100个编号、字段、相关题号、来源引用、70条独立话术及长段重复，然后生成 `data.js`、`evidence.js`、三个 Markdown 分册、完整正文和单文件离线版。不要手动编辑生成文件。

本地预览运行 `python -m http.server 8765`，打开 `http://127.0.0.1:8765/`。深链接格式：`#q=61`。部署到子目录无需修改资源路径。

## GitHub Pages

静态页面已就绪，根目录有 `.nojekyll`。首次发布需要在 Settings → Pages 选择 Deploy from a branch → main → /(root)。私有仓库能否启用 Pages 取决于账号方案；无需为了上传内容改变可见性。不要把 GitHub 仓库链接或离线版当成已经上线的 Pages 网站。
