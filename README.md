每题提供：先判断、第一步、准备成本、可能收益、示例表达、完整拆解、适用边界、参考范围、相关问题，以及一张四格行动卡。行动卡帮助你在沟通前写下事实、选择与需要确认的事项，可以直接复制填写。网页支持全文搜索、编号直达、阶段/处境/准备时间筛选、收藏、复制话术、深链接和打印当前题目。收藏仅存在浏览器本地。

## 三个阅读阶段

| 阶段 | 范围 | 主要用途 |
| --- | --- | --- |
| 基础应对 | 01—30 | 临时加活、拒绝、批评、责任与价值呈现 |
| 协作进阶 | 31—60 | 项目接口、利益分配、中层管理、推进与成长 |
| 高阶判断与选择 | 61—100 | 决策链、组织变化、资源机会、专业影响与职业转向 |

不用按顺序读完，也不用做完全部行动卡。先找与你的处境相近的一题，做一个低成本动作，观察结果再决定下一步。准备时间是编辑估计，收益是可能改善，不保证结果。

## 这一版改了什么

读取用户提供的ima三册PDF，共162页，核对1—100问的主题推进。31—100逐题重新写作，补齐利益分配、中层管理、组织收缩与职业转向等主题，使题目、摘要、话术和正文围绕同一个问题。前30问保留核心内容，修正抽取错误、缺失话术、未经核实的比例，以及关于离职、记录和沟通效果的绝对说法。

参考《高性价比人生指南》的按需阅读、投入收益、小步验证和适用限制，给100问加入各自的行动卡。场景分析、步骤与新写示例为独立编辑重构；原册提供场景参考，不构成方法效果的证据。没有上传原始PDF或整份抽取文本。具体阅读范围见[来源与核验](docs/来源与核验.md)，结构变化见[PDF对照与重构](docs/PDF对照与重构.md)。

## 维护与构建

正文唯一源为 `content/questions.json`，来源为 `content/sources.json`。运行 `python build.py` 验证100个编号、四格行动卡、相关题号、来源引用、70条独立话术及长段重复，然后生成网页数据、三个Markdown分册、完整正文和单文件离线版。不要手动编辑生成文件。

本地预览运行 `python -m http.server 8765`，打开 `http://127.0.0.1:8765/`。深链接格式：`#q=61`。部署到子目录无需修改资源路径。

## GitHub Pages

静态页面已就绪，根目录有 `.nojekyll`。首次发布需要在 Settings → Pages 选择 Deploy from a branch → main → /(root)。私有仓库能否启用Pages取决于账号方案。本仓库保持原有可见性。
